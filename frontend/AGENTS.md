# 项目教学约定

本项目使用者是 Java 后端开发者，正在学习 TypeScript、React、Vite 和 pnpm。

- 新增或修改前端源码时，优先使用便于学习的清晰写法，并补充中文语法注释。
- 对陌生语法、JSX、Hooks、异步流程和数据流，必要时逐行解释；可以使用 Java 类比，但要说明差异，避免误导。
- 注释要说明「语法含义、为什么这样写、数据如何变化」，不只翻译函数名。
- 保持注释与实际行为一致。重复的普通标签 / 样式不必机械注释每一行。
- 不要向严格 JSON 文件添加不支持的注释；配置解释可写入 docs/SYNTAX_READING_GUIDE.md。
- 不修改 node_modules、dist 或生成的锁文件来添加教学注释。
