同源计算，可重复导出

Java2D 输出 4883 × 2900 PNG。阴影使用日内高低价 / 同一均线，水平区域来自附件。

保留每次生成的 PNG、CSV、清单和 SHA-256。原作者的完整合约规则未知，本项目是方法复现。

生成与数据状态

“重新生成”只读取本地已保存数据，不会联网获取新行情。需要更新时，将富途 MCP 的新日线响应按下方格式导入；图表署期始终取最新交易日。

更新数据与导入格式

调用富途 MCP quote_history_kline，使用 US.ZNmain、ktype="2"、autype="0"。按年度或更短区间获取，边界重叠数日；每次最多 370 条，has_more 必须为 false。将成功响应封装如下。

{
  "source": "Futu MCP quote_history_kline",
  "retrievedAt": "实际获取时间（ISO-8601）",
  "request": {"symbol":"US.ZNmain", "ktype":"2", "autype":"0"},
  "response": {"ret_code":0, "data":{"kline_list":[...]}}
}

本地 Java 进程无法直接复用 Codex 会话的 MCP 身份；导入原始响应后自动合并、重新计算与导出。
