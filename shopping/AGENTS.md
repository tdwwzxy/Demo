# 项目约定

- 本项目面向 Java 后端开发者学习，React / TypeScript 的类型、Hooks、事件、JSX 和异步数据流要有清晰的中文注释。
- 访客浏览和下单免登录；所有运营写接口必须在服务端验证管理员身份，不能只隐藏按钮。
- 商品价格、库存和订单金额以服务端为准，金额使用 BigDecimal；下单和取消要使用数据库事务。
- 示例商品和参考金价必须标明演示性质，不得宣称实时行情、真实销售或已获得认证。
- 商品图片来自用户提供的参考截图，保留原图，通过前端布局显示商品区域；新增商品可上传自己的 JPEG / PNG。
- 不提交 data、上传目录、密码、日志和构建产物。涉及权限、订单、价格、上传的修改要运行相应集成测试。
